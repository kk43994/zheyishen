# 这一身

竖屏、自由走位、自动索敌弹道的人生构筑 Roguelite（V0.4）。玩家不能改变已经发生的事，只能在命运事件中左滑“咽下”或右滑“吐出”；走位、回应、五毒和穿戴道具会共同改变唯一攻击《一口气》。

## MVP 内容

- 每一局都由AI实时生成全新的出生故事、童年外号、受约束外貌 DNA 与初始数值底色；家庭底色×地域×基调×外号构词由代码掷轮盘抽定后交给AI执行，防止叙事塌缩
- 六章人生关卡（童年至暮年）、无限地图自由走位、自动索敌攻击，环境随年龄在奔跑中平滑渐变
- 70余件可穿戴人生道具，叠加改变角色外貌、弹体形状、颜色、轨迹与生命周期
- 每局生成式命运事件连成连续剧，回应改变贪、嗔、痴、慢、疑与后续构筑
- 当铺、以及地图上随机刷新的留灯间/里屋实体门（限时存在，走进去触发）
- Canvas 2D 参数化美术；AI只能选择白名单模板，不能自由生成PNG、SVG路径或数值

## 操作

- 战斗：虚拟摇杆/WASD 走位，《一口气》自动索敌攻击
- 命运：左滑“咽下”，右滑“吐出”；键盘可用 A/← 与 D/→
- 奖励、商城和特殊房：点击选择；数字键 1–3 也可选择

## 本地开发

```bash
npm install
cp .env.local.example .env.local
# 只在 .env.local 中填写 BLOOD_MOON_AI_API_KEY；该文件已被 Git 忽略
npm run dev
```

GPT 通过 Vite 后台代理调用，浏览器和构建产物拿不到密钥。后台日志会明确显示：

```text
[AI] abc123 origin -> gpt-5.6-luna
[AI] abc123 origin <- gpt-5.6-luna 7227ms
```

出生档案没有可游玩的本地保底：未配置、超时、上游失败或输出未通过白名单时，开场会停留在重试页，绝不会把示例人物塞进这一局。代码中的出生案例只用于AI风格参照。后续命运事件仍保留本地故障保护，避免一局已经开始后因临时断网丢档；抖音正式接入阶段将把同一生成协议换成平台 `tt.callAIChatCompletion`。

## 构建与打包

```bash
npm run package
```

上传包生成于 `release/zhe-yi-shen-mvp.zip`，压缩包根目录直接包含 `index.html`，平台校验上限为100MB。
