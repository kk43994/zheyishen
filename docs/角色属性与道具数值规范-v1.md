# 《这一身》角色属性与道具数值规范 v1

> 目的：让每件道具的"改什么、改多少、是倍率还是加减"都有唯一、可执行、可读懂的写法。参考《以撒的结合》的属性面板模型：**角色有一套基础属性（基线 = ×1.00 / +0），道具以倍率或加值在其上叠加。**
> 数据源：`src/game.ts` 的 `BASE_VECTOR`、`computeAttackVector()`、`HERO_BASE_SPEED`、`HeroState`。本规范如实反映当前代码的套用模型，不是另拍脑袋。

## 2. 三种记法（消除"倍率还是加减"的歧义）

道具 `numbers` 字段一律用下面三种记号之一，**不许再出现读不出是倍率还是加点的写法**：

1. **`×N` 倍率**（乘在基线上）——用于：伤害、射速/间隔、射程、弹宽、弹速、存活、移速、击退。
   - 允许等价百分号写法：`伤害 ×1.18` ≡ `伤害 +18%`，但同一属性全表统一，**且百分号只用于倍率类**。
2. **`+N / −N` 加值**（加减到基线上）——用于：弹数、穿透、追踪、散射、分裂率、范围爆炸、最大生命、零钱。
   - 整数量（弹数/穿透/生命/零钱）写整数：`穿透 +2`、`最大生命 −8`。
   - 小数量（追踪/散射/分裂）写小数或百分点：`追踪 +0.15`、`分裂 +12%`。
3. **布尔开关**：`折返：开`、`只散射→零波动` 之类。

### ⚠️ 唯一最容易写错的一条：暴击是"加百分点"，不是倍率
代码里 `critChance += 0.25`（基线 0.05 → 0.30）。所以「暴击 +25%」= **加 25 个百分点**，不是 ×1.25。
规范：**暴击一律写成加点** `暴击 +25%(点)` 或 `暴击 +0.25`，永远不写成 `暴击 ×N`。伤害的 `+18%` 才是倍率。两者虽然都带百分号，但暴击加在 5% 基线上、伤害乘在基准上——写法上用"(点)"或语境区分，审核时按本条判定。

### 复合与条件写法
- 常驻：`伤害 ×1.40 · 穿透 +2 · 弹速 ×0.55`（装满石头的书包）。
- 条件/成长：`每持有 1 件道具，伤害 ×(1+0.05)`（已注销工牌，按数量线性）；`每 5 枚零钱，伤害 ×1.06`（第一次工资）。写清"每 X 触发一次乘/加"。
- 负面不许漏：隐藏代价（雨衣的射速 ×1.18=变慢、name-sold 的永不暴击）必须进 `numbers` 或 `rule`。

## 3. 弹速默认偏快——分析与建议

**现状**：基准弹速 280，射程 232 → 一发飞到最远只需 `232 / 280 ≈ 0.83 秒`。在 360×640 竖屏、吸血鬼幸存者式走位下，弹体几乎"瞬达"，读不出《一口气》被吐出来、够不到远处的那种迟缓感，也削弱了"射程/弹速"这类道具的手感差异。

**建议**：把基准 `projectileSpeed` 从 `280` 降到 **`230`**（一发到最远 `232/230 ≈ 1.0s`，节奏更"呼吸感"，且给"弹速 ×"类道具留出更明显的上下浮动空间）。这是**平衡改动**，会全局变慢，需你拍板具体值（可选 220 / 230 / 240）。改动点：`src/game.ts:146` 的 `BASE_VECTOR.projectileSpeed`。

> 注：涉及弹速的既有道具（木剑不改弹速、书包 ×0.55、慢表 ×0.85、贪毒降速）都是相对基准的倍率，降基准后它们自动跟着慢，无需逐个改。

## 4. 叠加规则与割草爽感（数值系统的目的）

爽感不来自"开局就强"，而来自**经历不断叠加、把一团普通的《一口气》滚成夸张的样子**——这既是割草快感，也是"越活越重、这一生塑造了这一身"的叙事本身。起点必须弱（红线：开局一团最普通的气），夸张只能是构筑的结果。

### 4.1 两条叠加轴决定滚雪球
- **倍率类相乘 → 伤害指数增长。** 伤害/射速/弹宽等是 `×` 连乘：木剑 ×1.45 × 书包 ×1.40 × 愤毒 ×… 几件叠起来伤害轻松翻几倍。这是"数值爆炸"的主轴。
- **加值类累加 → 弹幕铺满屏。** 弹数/穿透/分裂/追踪是 `+` 累加：召唤继承类（五个哈五连发、纽扣额外弹、验孕棒复制、书包穿透+2、弹珠折射、分裂率）叠起来，一次呼吸打出一整片，从"一发细弹"变成"糊满屏"。
两轴一乘一加交叉，就是"单件看着克制、合起来夸张"的根源。

### 4.2 三层放大器（夸张视觉的触发点）
1. **材质反应**：水×电=麻痹、水×冰=冻结增强、纸×红笔=旧伤——弹体材质叠加时触发额外结算与特效。
2. **命名组合 COMBO**：集齐命名组合触发奥义插画 + 机制质变（正典已有 12 组）。
3. **协同标签 synergy「成双」**：湿×冰、锋利×骨节、重×爆炸、水×信号、追踪×折返，首次触发一局一次的强化与提示。
这三层是"爽感峰值"的落点：越到后期越频繁地炸出夸张画面。

### 4.3 爽感曲线（对应人生阶段）
- **童年/少年（早期）**：一两件道具，弹道略变形，伤害小幅上涨——刚学会用力。
- **青年/成年（中期）**：倍率开始相乘、召唤继承铺场，明显滚雪球——"这一身"成形。
- **中年/晚年（后期）**：一次《一口气》清半屏，材质反应/组合/协同连锁炸开——最夸张，也最接近"把一辈子的重量一口气吐出来"。
- **终局**：收灯人一件件剥掉道具，弹幕层层坍缩回最初那团普通的气——爽感的反面，正典的收束。

### 4.4 对数值书写的约束
- **单件保持克制、组合才夸张**：任何单件都不该一件封神；夸张必须靠 4.1 的叠加乘出来。否则塌成"一件顶所有"的数值堆砌，违背"机制即隐喻"。
- **留出乘算空间**：倍率类单件别动辄 ×3；留给多件相乘。加值类（分裂/追踪/弹数）是铺场面的主力，按"叠满会糊屏"来预估上限。
- **里屋高风险高回报**：里屋件（脊梁骨把负面全转增伤、提前花掉的十年预支5轮）就是"极端夸张构筑出口"，用永久代价换爆炸，是爽感的天花板档。
