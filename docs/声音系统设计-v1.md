# 《这一身》声音系统设计 v1

## 目标

声音不是为字幕做朗读，而是让玩家在战斗中偶然听见一段真实生活。每章至少有一次必然发生的听觉回收，以及一次由停留、道具或选择触发的隐藏声音。惊喜必须有前因；广播、电话和人物只能说现实里有理由说的话。

## 四层声音

1. **环境层**：雨、教室、站台、厨房、办公室、病房。章节转换时旧声音逐渐变成下一章的声音，例如下课铃的尾音接成列车关门提示。
2. **现实发声层**：老师、站内广播、护士、门禁、父亲。它们承担时间、地点、人物和事件，不讲哲理。
3. **回忆层**：已经真实听过的短句被年龄、选择和道具重新加工。回忆可以变远、变闷、缺字，但不能新增往事。
4. **条件回声层**：全部使用预生成固定语音；玩家的阶段、停留、生命、道具、Boss 状态和选择只决定哪些语音被听见以及采用哪种声音处理。

每条语音还必须携带一组玩家可见的“场景 · 声源”，例如“城南站台 · 广播”“医院来电 · 护士”。播放时游戏显示短暂字幕，不让声音线索依赖玩家猜测是谁在什么地方说话；静音玩家仍能看懂剧情，但开启声音才能听见距离、门后、电话和回忆层的差异。

## 表演规则

- 正式短句由已确认的 MiniMax 自定义声线与 Apache-2.0 Kokoro 中文声线共同承担，统一输出 32 kHz、64 kbps、单声道 MP3。
- 每句必须显式记录音色定位、语调、情绪、语速、音高、强度与行内动作标签；生成器不得用全局默认值覆盖逐句参数。
- 每句最多两个语气或呼吸标签，停顿标签不超过三个。
- 父亲禁止 `sad` 和 `angry`；默认 `calm`，情绪靠短停顿与句尾完成。
- 广播禁止 `(sighs)`、`(breath)` 等人物化标签。
- 暮年旁白允许一次 `(inhale)` 与一次 `(exhale)`，形成《一口气》母题。
- 不使用恐怖混响。电话、门后、广播和回忆效果由游戏运行时处理，源文件保持干净。

自然度优先级依次是：同一人物保持同一音色、按意群安排标点与停顿、使用接近日常说话的语速，最后才是情绪参数。`calm` 是默认情绪；只有“床下是不是有东西”“听见自己复述父亲”等确有心理转折的句子使用轻度 `fearful`，普通流程人物不额外表演。

MiniMax `speech-2.8` 文本只使用官方支持的行内动作标签。当前合同实际使用 `(inhale)`、`(exhale)`、`(breath)`、`(clear-throat)` 与 `<#秒数#>`；动作最多两个，精确停顿最多三个。动作标签不用于广播、门禁和电话系统声。

## 交互处理

- **咽下**：当本局“咽下”比“吐出”至少多两次，后续回忆语音低通到约 900 Hz，像压在喉咙后面。
- **吐出**：当本局“吐出”比“咽下”至少多两次，后续回忆语音提高高频清晰度；不等于正面选择。
- **未选择**：现实发声使用干声，不施加道德含义。
- 同时只允许一条叙事语音占主位；优先级只决定等待队列中保留哪一句，只有合同明确标记 `interrupt` 的关键句可以截断当前台词。关键语音播放时普通攻击音效降 4 至 7 dB，受伤与危险预警永不静音。
- 每条线都有冷却，死亡、暂停和切后台时立即停止。

## 固定资产边界

运行时不调用 TTS，也不按 AI 故事生成语音。所有声音在发布前预生成、人工试听、压缩并随包发布。随机性只作用于触发，不作用于台词内容和角色音色，因此不会出现等待、声线漂移、剧情越界或临时接口失败。

当前合同为 76 条固定语音，定义在 `src/voice-script.ts`。每条都具有结构化触发事件、条件、是否必播、优先级和打断规则；构建时少于 30 条直接报错。成年《响个不停》的固定八通中，第 2 通陌生号码有意保持静默；老婆、医院、妈妈、系统提示、父亲、同事与主角末句均有逐字匹配资产。留灯间 `light-room-left-this` 只在拿走“上一世的”物证时播放，沿用同一看守人音色但不复用入场台词。

声音默认开启；玩家第一次点击标题页“开始呼吸”时会直接解锁并播放包内预置音频，不再出现二次声音选择窗口。标题页与暂停设置仍可随时关闭声音，玩家主动静音后会在本机记住。`default-audio-v2` 迁移会把旧版本选择窗口留下的静音状态重置一次，保证升级后的草稿立即有声。

正式 MiniMax 批量生成使用 `npm run generate:voice`，试听阶段可用 `npm run generate:voice:draft`。当云端账户不可用时，`npm run generate:voice:local` 使用 Apache-2.0 的 `Kokoro-82M-v1.1-zh` 中文专用模型补齐缺失文件；它保留已存在的 MiniMax 成品，并按角色固定中文说话人、执行逐句语速。Kokoro 默认以整句连续生成和标点停顿优先；只有 ASR 证明连续生成会擅自增加词语时，才允许同音色分意群合成并插入合同停顿。MiniMax 版本仍执行 `<#秒数#>` 精确停顿；老婆与妈妈若改走 MiniMax，必须显式提供各自音色 ID，脚本拒绝回退到同一默认声线。`npm run validate:voice` 检查 76 条合同及运行时触发引用；发布前使用 `npm run validate:voice:strict`，任何缺失、损坏或清单不完整的音频都会阻止发布。

`npm run audit:voice` 使用独立 Whisper 模型反向转写全部成品，输出 `qa-report.json`，按字符错误率标记 `pass / review / fail`，并记录每秒字数。带 `--only=` 时按合同顺序合并更新，不覆盖其他已审计条目。它用于发现漏字、错音和过慢台词，不把同音字转写差异直接当成表演问题。

开发服务器的 `/voice-review.html` 是固定审听台：可按阶段、资产状态和关键词筛选，逐条核对场景、声源、现实台词、音色定位、语调、情绪、语速、音高、强度、动作标签、处理方式、触发标准与叙事目的，并直接试听发布包中的源 MP3。审听台不会调用 TTS；缺失文件会明确显示“待生成”，就绪文件会显示实际提供方。

终局声音有硬门槛：收灯人在主角仍穿着道具时不接受伤害；所有道具逐件归还后先响起“口袋空了”，再由暮年旁白说出“这一口气也可以放下了”。此时玩家再次攻击才恢复有效，它既是最后一次战斗输入，也是回答，不允许带着一身道具提前触发结局台词。

## 资产预算

- 固定语音当前 76 条，每条约 1 至 10 秒；总时长约 251.6 秒，正式文件约 2.05 MiB。严格发音 QA 为 73 条通过、3 条保留人工试听。
- 32 kHz / 64 kbps 单声道，预计总包体 1 至 3 MB。
- 环境循环与音乐另计；首版声音总预算控制在 8 MB 内。
- 源文件名与 `src/voice-script.ts` 的 `VoiceCueId` 完全一致。
