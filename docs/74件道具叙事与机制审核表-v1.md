# 《这一身》74 件道具叙事与机制审核表 v1（作废）

> **2026-07-23 作废原因：**本表主要检查了物件表面物性与数值/弹道是否相符，没有先还原物件背后的具体人生事件、隐秘诉求、求救方式以及未被接住的后果。它不能作为 74 件道具的定稿依据，也不授权替换运行时代码或美术资源。新版必须按“具体经历 → 隐秘诉求 → 暂时得到什么 → 真正失去什么 → 与其他经历如何产生构筑”重新设计。

## 审核标尺

- **A｜可保留**：物件、暗文案、正负机制互相解释，玩家不看说明也能感到联系。
- **B｜保留核心，小修**：梗或情绪成立，但有一项数值、代价或文案像后来硬接上去的。
- **C｜需要重做机制**：名字和经历有潜力，但当前效果仍是通用增伤、移速、扣钱，没把这件东西演出来。
- **文案基准**：《同桌的修眉刀》——“她说只是修眉，夏天却从不卷袖子。”写物与反常动作，不写诊断和结论。

## 初审结论

- **A｜可保留：46 件**。其中《同桌的修眉刀》《断掉的脊梁骨》《父亲的雨衣》《把名字卖掉的合同》《KTV 里没人听的那首歌》可以作为不同类型的设计基准。
- **B｜保留核心、小修：20 件**。主要问题是代价像配平数值，或文案直接说出了作者想让玩家自己悟到的结论。
- **C｜需要重做机制：8 件**：校服纽扣、旧工牌、卡册、砍一刀链接、医院共享充电宝、健身房年卡、朋友验证，以及现有统计中与物件联系最弱的通用数值机制。
