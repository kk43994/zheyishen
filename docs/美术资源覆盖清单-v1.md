# 《这一身》美术资源覆盖清单 v1

> 审计口径：只统计游戏代码当前实际加载的资源。`output/` 下的生成图全部视为候选，不因“已经生成”而算作运行时覆盖。

## 结论

当前 MVP 已引用的美术资源在结构上完整：没有缺图、空映射或错误尺寸。统一风格仍有两层工作：现有运行时资源按正典规范持续校色；新候选必须经过静态确认后才能接入。

统一视觉基线是：非战斗界面使用“人生档案”，持续战斗使用“流动人生场”。两者共享旧纸、深墨、旧红、雨衣黄、医院蓝灰色板，以及 1 像素轮廓、左上光源和最近邻缩放规则。深墨只负责轮廓、危险边缘与终局夜色，前五章战场使用可辨认的中间调和随年龄变化的日常光线。详见 `docs/美术资源制作规范-v1.md`。

功能特效允许少量蓝白、青色等语义强调色；白色主角发型图是代码蒙版，不计入可见色板。风格审阅以最终合成画面为准，不能用“所有像素必须落在同一张色卡”替代视觉判断。

## 自动门禁

`npm run validate:art` 现在检查：

- 主角三层共 12 张动作图集的尺寸、逐帧非空和动作偏移完整性；
- 19 张运行时敌人图集的尺寸与有效动作帧；
- 74 个道具定义与图标索引一一对应；
- 全部 UI、世界、房间、VFX 图集的尺寸、映射、透明 RGB 和地面/纹理接缝；
- 12 张组合插画无缺项；
- 生成清单引用路径没有失效。

任何一项破坏都会阻止正式打包。

`npm run audit:art-style` 额外生成同一倍率的全家族审阅板与量化报告：

- `output/art-audit-v1/style-consistency-board.png`
- `output/art-audit-v1/palette-normalization-preview.png`
- `output/art-audit-v1/style-consistency-report.json`

它把主角、19 组敌人、74 个道具、运行时摆设、待确认摆设、弹体和命中特效放在同一画面中比较，并提供一张机械色板重映射的诊断对照。该对照已经证明“所有像素强制吸到精确色值”会损坏部分暗色敌人的材质，因此不能作为直接接入方案。弹体与命中特效不进入强制重映射，因为功能语义色优先于机械色值统一。量化项只用于发现离群资源，最终仍必须经过实机视觉审阅；脚本不会自动替换运行时资源。
