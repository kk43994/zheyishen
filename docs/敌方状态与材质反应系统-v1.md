# 《这一身》敌方状态 · 材质反应系统 v1

> 目标：让**敌方 debuff 从道具的现实隐喻长出来，靠材质叠加互相反应**。不引入通用 RPG 的火冰雷毒；每种状态都是一段人生的形状。
> 运行时数据源：`EnemyUnit` 的 `wetTimer / freezeTimer / paralyzeTimer / rawTimer+rawStacks / readDamage+readTimer / heavyTimer+heavyStacks / controlFatigue`；弹体主材质由最终 `ProjectileForm` 决定，复合水/信号/骨材质继续读取 `ProjectileVisual`。

## 1. 运行时现状
- 命中统一进入 `applyProjectileMaterialReactions()`；暴击只替换命中特效行，不再丢失弹体原本的材质反应。
- 湿、冻、麻、旧伤、挂账、沉已经拥有独立字段、计时、战斗作用和 `12×12` 状态标记。
- 麻痹与冻结都会真正停止普通移动/攻击；沉同时拖慢逼近与攻击频率，湿提供轻微减速。
- 精英与 Boss 的连续冻/麻会受到 `controlFatigue` 递减，不影响湿、旧伤、挂账、沉等软状态。

## 2. 六种敌方状态（每种都是一段人生的形状）

| 状态 | 现实隐喻 | 机制 | 头顶标记 | 字段 |
| --- | --- | --- | --- | --- |
| **湿** wet | 淋过雨的、哭湿的、擦不干的 | 本身仅微减速 5%；让冻/麻反应更强 | 水滴 | `wetTimer` |
| **冻** chill | 冷掉的关系、僵住的沉默 | 短暂定身；湿态下概率更高、时间更久 | 冰花 | `freezeTimer` |
| **麻** numb | 被已读、被撤回、通讯里的麻木 | 短暂无法行动（比冻更短、更频） | 电弧 | `paralyzeTimer`（现有） |
| **旧伤** raw | 反复被翻开的旧账、没好的伤 | 最多三层，每层使后续伤害 +6% | 裂痕 | `rawTimer / rawStacks` |
| **挂账** debt | 迟到的清算、拖着的账单 | 命中先不结算，倒计时到点连本带利一次爆出；目标先死则落空 | 已读/¥ | `readDamage/readTimer`（现有） |
| **沉** heavy | 被压得动不了、懒得再挣 | 最多三层，同时拖慢攻击与逼近，偏软控不锁死 | 下坠箭 | `heavyTimer / heavyStacks` |

> 设计取舍：不做"烧/毒/流血"这类通用元素——它们没有对应的人生隐喻，会滑回普通 RPG，违背机制即隐喻。**沉**是我补的一条"你没想到的"：它对应书包/枕套/矿泉水那类"被生活压住动不了"的道具，是纯软控，专门喂给站桩/对峙流构筑。

## 3. 材质 → 状态映射（弹体材质决定挂什么 debuff）

弹体已带 `materials`。规则：命中时按材质概率挂对应状态，**材质来自道具的现实属性，不是玩家选元素**。

| 弹体材质 | 携带道具（举例） | 命中挂载 |
| --- | --- | --- |
| water（湿） | 父亲的雨衣、我一直在哭、雨滴类 | 湿 |
| 冰 | 小卖部的冰柜 | 冻（湿态增强） |
| sound（声/信号） | 领导撤回的六十秒语音、KTV、没打出去的电话 | 麻（过水时范围麻） |
| paper 红笔 | 写满红叉的练习册 | 旧伤 |
| bone（骨节） | 断掉的脊梁骨 | 旧伤（+18%，已有协同「旧伤口上再来一刀」） |
| 延迟（已读/账） | 凌晨三点的已读、网贷合同、没按下发送的离婚协议 | 挂账 |
| 重（沉） | 装满石头的书包、没洗的枕套、相亲桌上没拆的矿泉水 | 沉 |

## 4. 反应矩阵（材质×状态 = 割草爽感的放大器）

反应是"两段无关的经历撞在一起"的机制版留白，触发即一次夸张视觉峰值（承接 [[角色属性与道具数值规范-v1]] 第 4 节的爽感曲线）。

| 反应 | 触发 | 效果 | 现状 |
| --- | --- | --- | --- |
| 湿 × 冰 = 冻得更死 | 冰弹命中湿敌 | 冻结时长×1.5、概率↑ | 已实现 |
| 湿 × 声 = 水是导电的 | 声波命中湿敌 | 范围麻痹（92px 内溅到周围） | 已实现 |
| 旧伤 × 任意 = 旧伤口上再来一刀 | 命中带旧伤的敌 | 每层易伤 +6%，三层共 +18% | 已实现 |
| 挂账 × 范围爆炸 = 一次性清算 | 范围炸到挂账群 | 全部挂账提前引爆 | 已实现 |
| 沉 × 冻 = 压碎 | 冻住沉重的敌 | 该次伤害×1.4 | 已实现 |
| 沉 × 挂账 = 越拖越重 | 沉敌带挂账 | 每层沉使挂账累计量 +12% | 已实现 |
| 湿 × 追踪折返 = 那天雨太大 | 已有组合 | 信纸浸湿变慢变重穿透 | 已实现（组合） |

## 5. 我补的"你没想到的"

1. **状态统一视觉语言**：现在只有 freeze/已读两个头顶标记。给六种状态各一个统一小图标（第 2 节"头顶标记"列），玩家一眼读出敌人身上叠了什么——这是割草可读性的关键，也让反应触发的夸张画面有落点。
2. **硬控抗性递减，软控不抗**：Boss/精英对**冻、麻**（定身类硬控）有递减抗性（连续被控时长衰减），否则一套控到死没意思；对**湿、旧伤、挂账、沉**（软控/易伤/延迟）**不抗**——保证割草爽感能作用于 Boss，但 Boss 不会被硬控锁死。这条平衡是"夸张但不破坏节奏"的闸门。
3. **状态叠加与上限**：同状态刷新取 max（现有写法），旧伤/挂账可叠层但设层上限，防止无限滚雪球把后期变成一击。
4. **状态喂爽感的方式**：反应触发 = 视觉峰值落点（第 4 节）。中后期弹幕铺开时，材质叠加让屏上不断炸出冻裂/电弧/清算，这就是"叠加规则涌现夸张效果"的可见形式。
5. **终局收束**：收灯人剥离带状态的道具时，场上由该道具挂的残留 debuff 一并消退——弹幕和控场层层坍缩回最初那团普通的气，和 [[project-zheyishen-game]] 的走马灯正典对齐。
6. **与五毒解耦**：五毒（贪嗔痴慢疑）是**主角自身**的属性偏移，本系统是**敌方**状态，两套不共字段、不混淆；避免玩家把"敌人身上的旧伤"和"自己身上的痴毒"看混。

## 6. 生产与验证
- 运行时统一入口：`game.ts::applyProjectileMaterialReactions()`。
- 自动门禁：`npm run validate:materials` 校验状态字段、四条反应、11 种命中特效行和 Image2 状态图来源。
- 开发实机场景：`projectile-mechanic` 的 `conduct / crush / raw / settle` 分别验证导电、压碎、旧伤和提前清算。
- 全程保持：状态从道具现实属性长出来，禁止通用元素；单件克制、组合才夸张。
