## B 级 —— 打磨与卫生

- 引导改事件驱动一次性提示（命运牌/按住取物/图鉴各一条，位掩码存 onboarding）——中
- reducedMotion/highContrast 落盘 localStorage；全屏红闪走 reducedMotion（光敏）；音量滑杆支持拖动；暂停菜单加物证册入口——各小
- 8px/9px 字号占 62%：给高对比开关追加 +1px 字号副作用——中
- 出生特质正负面加 ＋/－ 前缀（色弱）——小
- 名册页「只读·不参与下一次出生」文案与上一世物证机制矛盾，改口——小
- 出生档案"截图态"（档案完成后主角像放大 1.8x+现场生成章，做成能直接发社交平台的一帧）；初始三选一保底一件组合件让首局能见奥义插画——中

## 建议的执行切法

1. **第一批（S 级全量 + A3/A4）**：全部小成本、零新资产、评委直接受益——一个工作时段可完成；
2. **第二批（A1 平台滤镜 + A2 五毒 + A9 出生预取）**：中成本、体验跃迁最大；A1 需要真机验证 WebView WebAudio；
3. **第三批（A5/A6 需新文案终审 + A7/A8 动画链路）**：涉及正典文案的先出 A/B 稿给用户挑；
4. 文档卫生（A10 小项 + B 级文档项）随批顺手做。
