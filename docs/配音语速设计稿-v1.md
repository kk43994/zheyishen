# 配音语速设计稿 v1（讨论稿，未实施）

> 起草时的问题：扩充前 51 条的 speed 挤在 0.78–1.06 的窄带里，所有人节奏趋同，不像真人。当前合同已经扩至 93 条，本稿仍作为语速设计依据保留。
> 原则：**语速不是角色属性，是场景属性**——同一个人赶时间和累了的时候语速完全不同。
> 本稿只动 delivery 参数（speed / 停顿 / 情绪联动），不动任何台词文字。

## 一、五档场景语速带

| 档 | 场景逻辑 | speed 区间 | 生活原型 |
|---|---|---|---|
| ① 连珠炮 | 忙碌的职业口径：说完这句要说下一句 | **1.05–1.16** | 护士报住院信息、招聘方走流程、同事补工作提醒、叫号、会议里 |
| ② 制式播报 | 机构声：清楚第一，稍快但不催 | **0.98–1.14** | 广播、门禁、银行客服；「车门即将关闭」是本档上限（唯一带催促感的播报） |
| ③ 日常家常 | 顺口说的普通话：不快不慢 | **0.95–1.06** | 照料者门外叮嘱、老师课堂交代、孩子随口问、房东报条件 |
| ④ 疲惫·年长·耳语 | 没力气快，或刻意压低 | **0.74–0.92** | 老婆的电话、妈妈的电话、年长邻居、收灯人、耳语议论 |
| ⑤ 父亲与暮年的他 | 全游戏最慢的两个声音，短句一字一顿 | **0.72–0.84** | 父亲三句、成年主角复述父亲、旁白首尾、收灯处 |

关键设计：**①和⑤必须拉开到 1.4 倍以上的差距**（1.15 ÷ 0.78 ≈ 1.47），玩家才会在"同事的电话"切到"父亲的电话"时被节奏落差击中——这本身就是叙事（世界催他，父亲不催）。

## 三、语速之外的两个升级（本稿一并讨论）

**A. 停顿的场景化**：现在 `<#x#>` 的秒数是拍脑袋的。提案按停顿的"含义"定长：
- 收回型（父亲「没什么事。<#…#>你忙吧」）：**加长到 0.8–1.0s**——那个停顿里是没说出口的话；
- 等待型（「还等你吗？」句尾）：保持 0.3s 左右；
- 忙碌型（护士/同事句中）：**压到 0.15–0.2s**——忙人不真停。
- 改动只调秒数，不增删标签（增删涉及正典文本，单独报批）。

**B. 情绪与语速联动校验**：`sad`/`fearful` 的句子不允许落在 ①② 档（伤心的人快不起来）；`calm` + ①档 = 职业性冷淡，是我们要的效果。写进 validateVoiceScript 当门禁。
