# 《这一身》Boss 设计书：沉默的父亲

> 版本：V2.0 完善讨论稿  
> 日期：2026-07-19  
> 所属章节：成年 · 屋檐下的家  
> 设计范围：人物、叙事、双阶段战斗、视听、美术管线、技术落地与验收

---

## 1. 先写两件事

> 单位让他回去等通知那天，他先问你为什么只考了九十二分。

> 他说只是顺路，鞋里却倒出一小滩水。

前一句是他给主角造成的伤。后一句是他没有说出口的爱。

“沉默的父亲”不需要再解释更多。他是一个受了委屈会迁怒孩子、看见孩子淋雨又会绕半座城去接的普通人。

## 2. 角色定义

父亲小时候哭，大人让他站直。

后来轮到他当大人，他只记得“站直”。

他没有学会怎么说累、怎么求助、怎么道歉。工作、钱、身体和面子压过来时，他先把雨衣扣紧，再回家问主角作业写完没有。

他以为孩子看不见自己的弱小，家就还没有塌。主角看见的却只有一张冷脸、一句命令和永远说不清的沉默。

这场 Boss 战不替父亲原谅自己，也不要求主角原谅父亲。玩家只需要看见：严厉是真的，迁怒是真的，雨里那双湿鞋也是真的。

## 3. 叙事边界

### 必须成立

- 父亲是普通人，不是恶魔、暴君或献祭自己的圣人。
- 第一阶段的压迫来自孩子眼中的体量差和权威，不来自机甲、骑士或怪物化。
- 第二阶段的小孩会主动迁怒主角。他不是纯洁无辜的受害者，也不是躲在外壳里等玩家发现的彩蛋。
- 看见父亲的委屈，只能解释伤害从哪里来，不能取消伤害。
- 温情必须落在动作、物件和玩法上，不能用长对白告诉玩家“父亲其实爱你”。

### 禁止出现

- “爸爸都是为你好”的总结式说教。
- 临死前完整道歉、强制拥抱或主角当场原谅。
- 雨衣开胸后露出一张放大的方脸。
- 小孩被画成可爱吉祥物、无害宝宝或搞笑撒泼。
- 父亲变成金属铠甲、机甲驾驶舱、骑士、僵尸或肉体怪物。
- 小孩在死亡帧里碎裂、流血或被玩家残酷消灭。

## 4. 玩家看见的文案

文案遵守《同桌的修眉刀》的基准：写物，不写理；先让人看见，再让人自己难受。

| 时机 | 文案 |
|---|---|
| 章节进入 | 他管那间屋子叫家。房东管它叫房源。 |
| 章节副标题 | 他说只是顺路，鞋里却倒出一小滩水。 |
| Boss 出场 | 雨声先到，父亲后到。 |
| Boss 名称下方 | 他还站着。 |
| 转阶段 | 雨衣倒下去，里面有人哭得喘不上气。 |
| 第二阶段短句 | 他说没有哭，手背却一直在擦脸。 |
| 击败 | 雨衣留下了。话还是没说。 |
| 遗物描述 | 他说只是顺路，鞋里却倒出一小滩水。 |

战斗中不连续弹台词。攻击名只在第一次出现时短暂显示一次。

## 5. 遭遇结构

整场战斗按五个画面推进：

1. 雨先落下来，普通怪潮停下。
2. 高大的父亲走进场内，站到主角和雨之间，再转身面对主角。
3. 他用严厉、克制、重复的动作逼迫主角后退。
4. 半血时雨衣失去支撑，父亲的体量从巨人缩回一个哭泣的小孩。
5. 小孩发完脾气后脱力坐下，旧雨衣留在主角这一边。

这不是“打败坏父亲后发现他也可怜”。这是主角第一次同时看见伤害和来处。

## 6. 战斗场地：《漏雨的屋檐》

Boss 出场后，场景保留折叠桌、热水瓶、纸箱和门，不新增幻想建筑。

雨从固定方向斜着扫过。它不是持续高伤害，而是缓慢、清晰、可绕开的环境压力：站在雨里会受到轻微减速与间歇小伤害。

父亲宽大的身体会挡住雨，在固定雨向的背风侧形成一块随他移动的干地。干地不跟随父亲的朝向旋转。地面不画发光安全圈，只让雨点、积水和反光自然缺一块。

玩家不需要文字教学。第一次雨幕到来前，父亲会先站到主角与雨之间。

## 7. 第一阶段：《站好》

### 7.1 状态

这是主角记忆里的父亲：高大、严厉、很少解释，永远像是知道正确答案。

雨衣扣到最上面。肩膀宽得不自然，帽檐压住整张脸。外侧湿透，内侧仍然是干的。右口袋补过两次，一只袖口比另一只更白。

### 7.2 体量与数值方向

- 运行时像素倍率：`4x`。
- 碰撞半径目标：约 `34-36`。
- 移动：慢、直接、少横跳。
- 防御：保留现有单次伤害最多 `4` 点的盔甲规则。
- 生命区间：总生命的前 `50%`。
- 攻击节奏：前摇清楚、范围大、频率低。

不采用“第一阶段不能杀死主角”的隐藏规则。温情必须让玩家看得见，不能靠系统偷偷留一滴血。

### 7.3 攻击一：《进去》

父亲先把一只宽袖抬到主角面前，随后横向推开。

- 大扇形近战。
- 中等伤害，强击退。
- 击退方向最多向最近的干地边缘偏转约二十五度，不让主角穿过父亲身体，也不把主角直接推进雨幕深处。
- 动作像把孩子赶回屋里，不像持盾冲锋。

### 7.4 攻击二：《站好》

父亲抬手指向主角。地面出现一条窄而直的预警线，随后重步压过去。

- 直线压迫攻击。
- 预警时间长于普通怪冲刺。
- 命中后主角短暂减速，不眩晕。
- 手指必须是人的手，不能画成武器或爪子。

### 7.5 场地动作：《外面冷》

雨幕加重时，父亲停止追击一小段时间，转身迎着固定雨向站住。背风侧的干地随之扩大。

玩家可以趁机输出，也可以躲雨。父亲不会回头看主角。

这个动作不显示名字。

### 7.6 第一阶段动作图集

| 动作 | 关键表演 |
|---|---|
| Idle | 一只手捏住衣襟；肩膀几乎不呼吸；雨从帽檐连续落下 |
| Move | 湿鞋拔地；上半身保持僵硬；每一步都很重 |
| Attack | 指人、抬袖、推开；动作始终受控 |
| Hurt | 不后仰；先缩肩，再立刻按紧衣襟 |
| Transition | 第一颗扣子松开；手去扣；肩线失去支撑；整件雨衣塌落 |

## 8. 转阶段：《雨衣倒下去》

半血时停止普通更新约一秒。

不使用爆炸、金环、怒吼和红光。雨声先断一下，只剩扣子落地和一次吸不上气的哭声。

父亲伸手去扣最上面的扣子。手碰到衣襟以前，宽大的肩膀先塌下去。雨衣落地后，画面中央不再有成年人，只剩一个八至十岁的男孩。

字幕：

> 雨衣倒下去，里面有人哭得喘不上气。

转换同时完成：

- 切换第二阶段图集。
- 显示倍率从 `4x` 降为 `2x`。
- 碰撞半径降到约 `18`。
- 取消第一阶段伤害上限。
- 移动速度提高。
- 在原地生成“落下的雨衣”场地对象。

## 9. 第二阶段：《我没有哭》

### 9.1 状态

这不是父亲身体里的另一个人。这个孩子就是父亲没有长大的那一部分。

他受了委屈不会说，只会迁怒离自己最近的人。真正的自己被主角看见后，他先捂脸，再哭，再把主角推开。

小孩必须危险。玩家理解他，不代表可以站着挨打。

### 9.2 体量与数值方向

- 运行时像素倍率：`2x`。
- 碰撞半径目标：约 `18`。
- 移动：短促、突然、带踉跄。
- 防御：无伤害上限。
- 攻击节奏：前摇短于第一阶段，但每轮攻击后有明显脱力。
- 视觉高度接近主角，不再保留巨人感。主角实际绘制面为 `40x56`，第二阶段 `32x32` 图集按 `2x` 显示后可获得接近的占屏高度。

### 9.3 攻击一：《不许看》

小孩用手背擦脸，发现主角仍在看他，随后捂住脸向前冲撞。

- 一次短蓄力、两段冲撞。
- 每段之间会重新寻找主角方向，但转向角受限。
- 撞到落下的雨衣会提前停止并摔坐一下。
- 主要威胁来自速度，不来自超大范围。

### 9.4 攻击二：《都怪你》

小孩原地连续跺脚，哭声越来越大。

- 三次由小到大的地面雨圈。
- 前两圈用于逼走位，第三圈伤害最高。
- 跺脚时两只拳头攥紧，不能出现法师施法姿势。
- 雨圈遇到落下的雨衣会缺一个口，形成可读安全角。

### 9.5 攻击三：《我没有哭》

小孩一边擦脸一边乱挥手，眼泪甩成一排短弹道。

- 扇形泪滴弹道，数量少、间隔清楚。
- 弹道不追踪。
- 落下的雨衣可以挡住泪滴。
- 攻击结束后小孩蹲下喘气，形成主要输出窗口。

### 9.6 第二阶段动作图集

| 动作 | 关键表演 |
|---|---|
| Idle | 肩膀抽动；一只手擦脸；另一只手攥紧 |
| Move | 缩身、迈大步、差点绊倒；不能跑成可爱循环 |
| Attack | 捂脸冲撞、跺脚、挥拳；小孩主动造成伤害 |
| Hurt | 先愣住，再哭得更厉害；手脚仍是正常儿童比例 |
| Death | 发完脾气后脱力坐下，最后抱住膝盖；不碎裂、不流血 |

## 10. 温情怎么进入玩法

不写“父亲其实爱主角”。只保留四件看得见的东西。

### 10.1 湿鞋

第一阶段父亲迎雨的一侧更深、更湿。移动帧会从鞋底甩出水点。章节副标题只写那一小滩水。

### 10.2 干地

第一阶段父亲背风侧始终少一块雨。玩家可以利用它躲避环境压力，但必须靠近一个正在攻击自己的父亲。

### 10.3 落下的雨衣

第二阶段雨衣不消失，也不继续变成怪物。它成为场地里的软掩体：挡泪滴、截断雨圈、让冲撞提前停止。

每轮发完脾气，小孩会装作不经意地把雨衣往主角方向踢一点。动作很小，不配字幕。

### 10.4 干燥的内面

击败后，雨衣外侧朝雨，干燥的内面朝主角。奖励界面随后出现。

没有拥抱。话还是没说。

## 11. 击败与遗物

最后一击不是杀死小孩。小孩哭不动了，坐下，抱住膝盖。画面停一小段时间，只剩雨打在旧雨衣上的声音。

落幕字幕：

> 雨衣留下了。话还是没说。

《父亲的雨衣》继续保留矛盾：

- 第一次伤害被挡住。
- 受伤会把当前《一口气》拆成雨滴。
- 射速下降，身体变重。
- 穿上后外形更宽，其他物件被迫挪到雨衣外面。

它不是“父爱证明”，也不是纯负面创伤。它只是父亲留下来的那种保护方式。

## 12. 视听设计

### 12.1 色彩

- 雨衣：旧橄榄黄绿，不用鲜亮黄色。
- 阴影：墨紫灰，不用纯黑铺满全部细节。
- 湿边：冷蓝灰，只出现在迎雨侧。
- 内衬：暗而偏暖，与湿冷外侧拉开温差。
- 小孩：灰黑旧衣、暗发、低饱和肤色。
- 眼泪：只用一档冷亮色，避免夸张蓝色水柱。

### 12.2 声音

- 第一阶段：湿鞋、布料、扣子、压低的呼吸。
- 第一阶段不连续说话。攻击只允许极短的“进去”“站好”。
- 转阶段：雨声瞬间变小、扣子落地、吸不上气的第一声哭。
- 第二阶段：哭声要像努力忍住后失控，不能像婴儿、卡通角色或恐怖尖叫。
- 击败：不放胜利重音，只保留雨打布料和一次很轻的鼻息。

### 12.3 镜头与反馈

- 第一阶段出场使用轻微低频震动，不快速推镜。
- 转阶段镜头不放大孩子，体量骤降本身就是重点。
- 第二阶段跺脚可以轻震，冲撞不使用巨型爆炸。
- 击败时镜头停在雨衣和小孩之间，不只拍小孩的脸。

## 13. 五套完整美术方向

五套都遵守同一人物与玩法，只改变第一阶段“严厉的大人”怎样站、第二阶段“发脾气的小孩”怎样延续同一个动作。

### 方案一：《门口的人》

- 第一阶段：雨衣像一扇闭合的旧门，中央扣线像门缝，肩膀最宽。
- 第二阶段：门形雨衣倒在身后，小孩站在衣摆形成的门槛前哭闹。
- 动作对应：大人关门、挡门；小孩扑上来不让主角靠近。
- 温情细节：雨衣倒下后，门槛里面没有雨。
- 风险：门的隐喻不能画得像真正木门。

### 方案二：《雨里的人》

- 第一阶段：一边肩膀和鞋明显湿透，另一边形成宽大的遮雨弧。
- 第二阶段：大雨帽落在小孩背后，像一把坏掉的伞；小孩从下面冲出来。
- 动作对应：大人用身体挡；小孩用身体撞。
- 温情细节：干湿两侧最清楚，最容易让玩家不看文字也读懂。
- 风险：轮廓不能像伞怪或披风英雄。

### 方案三：《说没事的人》

- 第一阶段：三层衣襟叠在一起，旧扣、补丁和口袋都是大块像素。
- 第二阶段：三层衣服全部落地，小孩肩上只挂着一只过长袖口。
- 动作对应：大人把衣服越裹越紧；小孩用过长袖口擦泪、乱挥。
- 温情细节：补过两次的右口袋在两个阶段都出现。
- 风险：层数必须控制，32×32 下不能糊成纹理。

### 方案四：《学会站直》

- 第一阶段：高、直、方，肩线刻意水平，像一根不敢弯的柱子。
- 第二阶段：空雨衣垂直塌下，小孩跌出来后始终驼背、歪斜、站不稳。
- 动作对应：大人每个动作都是直线；小孩每个动作都是弧线。
- 温情细节：第一阶段迎雨时仍然微微向主角一侧倾斜。
- 风险：第一阶段不能画成军人或制服权威。

### 方案五：《没有抱下去》

- 第一阶段：过长袖子交叉压在胸前，想伸手时最后变成推开。
- 第二阶段：小孩先抱住自己，随后松手、哭喊、用双拳推打主角。
- 动作对应：大人把手收回去；小孩把手失控地甩出去。
- 温情细节：雨衣落地时两只袖子朝主角张开，但没有碰到他。
- 风险：交叉袖口不能像束缚衣。

## 14. 美术管线规格

### 14.1 候选阶段

五套方案都使用管线机生成，不手画、不拼贴现有父亲资源。

每套生成两张独立绿幕设定板：

1. 第一阶段：Idle、Move、Attack、Hurt 四个关键姿势。
2. 第二阶段：Idle、Move、Attack、Hurt 四个关键姿势。

两阶段分开生成，避免大父亲和小孩共用相同画面占比后导致小孩糊掉。

### 14.2 程序规整

- 绿幕抠像。
- 分格与独立裁切。
- 最近邻降采样到 `32x32`。
- 项目统一调色板量化。
- 第一阶段统一脚底与肩宽。
- 第二阶段统一儿童头身比和泪痕位置。
- 由生成关键姿势构建 Idle、Move、Attack、Hurt、Death/Transition 行。
- 禁止再次人工贴一张脸；可读性必须来自完整原始姿势和整体降采样。

### 14.3 运行时图集

- 单帧：`32x32` RGBA。
- 图集：`128x160`。
- 行顺序：Idle、Move、Attack、Hurt、Death/Transition。
- 每行最多四帧，不足帧复制最后一帧补齐。
- 第一阶段按 `4x` 最近邻显示。
- 第二阶段按 `2x` 最近邻显示。

### 14.4 每套交付物

1. 两张原始生成设定板。
2. 两套完整动作图集。
3. 第一阶段 `4x`、第二阶段 `2x` 的动作对比图。
4. 与主角并排的实际体量图。
5. 转阶段连续帧预览。
6. 游戏场景内第一、第二阶段截图。
7. 透明边界、脚底基线、色数和帧尺寸检查清单。

候选未选定前，不覆盖正式运行时资源。

## 15. 技术落地

现有代码已经具备以下基础：

- `silent-father` 半血切换第二阶段。
- 第一阶段单次伤害上限。
- 第二阶段独立图集 `silent-father-p2`。
- 第二阶段移动加速。
- Boss 独立血量、半径和死亡流程。

需要新增：

1. 按资源或阶段决定显示倍率：第一阶段 `4x`，第二阶段 `2x`。
2. 转阶段时同步修改碰撞半径与攻击状态。
3. 父亲专用攻击状态机，区分《进去》《站好》《不许看》《都怪你》《我没有哭》。
4. Boss 雨幕与动态干地区域。
5. “落下的雨衣”场地对象及泪滴、雨圈、冲撞阻挡判定。
6. 第一阶段 Transition 和第二阶段 Exhausted 的专用死亡行播放。

这些改动都位于现有战斗、敌人渲染和特效层内，不需要重写地图或角色系统。工作量中等，主要风险在动作读性与雨衣掩体判定，不在底层架构。

## 16. 验收标准

### 人物

- 不看设定文字，也能看出第一阶段严厉、第二阶段委屈且迁怒。
- 玩家能同时感到“他伤害了主角”和“他曾经替主角挡过雨”。
- 战后不要求玩家原谅。

### 美术

- 第一阶段明显大于现有版本，轮廓不糊、不像骑士或机甲。
- 第二阶段是完整哭泣小孩，不再出现悬浮方脸。
- 两阶段缩放后均保持硬像素，无插值模糊。
- 雨衣内外干湿关系能在游戏尺寸下读出。

### 动作

- 第一阶段动作受控、直、重。
- 第二阶段动作失控、弯、快。
- 小孩主动攻击，且攻击不卖萌。
- 转阶段只靠雨衣塌落和体量变化就能读懂。

### 玩法

- 干地和落下的雨衣都能被玩家主动利用。
- 温情机制不会让 Boss 失去威胁。
- 所有攻击有清晰前摇，移动端可以躲避。
- 第二阶段缩小碰撞体后仍容易识别和命中。

### 文案

- 不出现“父爱”“创伤”“代际”“原谅”等解释词。
- 每句都能对应一个看得见的物件或动作。
- 文案密度不高于《同桌的修眉刀》。

## 17. 最终推荐

角色与玩法基线采用本设计书全部共同规则。

五套美术方案全部进入管线候选，不先锁定其中一套。选择时优先看三件事：

1. 第一阶段是否真的像孩子眼里的高大父亲。
2. 第二阶段哭泣、迁怒和攻击是否在 `2x` 尺寸下清楚。
3. 不看文字时，雨衣是否仍然像一件留下干地的普通旧雨衣。

在这三件事成立以前，不发布正式图集。
